# Countries Explorer

Countries Explorer 

---

## Running locally

### Install dependencies

```sh
pnpm install
```

### Start the development server

```sh
pnpm dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

---

## Technologies

* [Next.js](https://nextjs.org/)
* [React](https://react.dev/)
* [TypeScript](https://www.typescriptlang.org/)
* [Tailwind CSS](https://tailwindcss.com/)
* [Zustand](https://zustand-demo.pmnd.rs/) (state management)
* [TanStack Query](https://tanstack.com/query) (server state)
* [REST Countries API](https://restcountries.com/) (country data)
* [Unsplash API](https://unsplash.com/developers) (dynamic images)

---

## Features

### Home Page
* **Integrated Search** with real-time filtering
* **Region Filtering** with instant results
* **Countries by Region** organized display

### Country Details
* **Dynamic Background Images** from Unsplash API
* **Comprehensive Information** including:
  - Population, capital, region
  - Languages and currencies
  - Geographic data and country codes
  - Interactive maps
* **Responsive Design** optimized for all devices

### Advanced Features
* **Real-time Search** with keystroke-based filtering
* **Multi-criteria Filtering** by region and search terms
* **Caching System** for optimal performance
* **SEO Optimized** with static generation
* **Glass Morphism UI** with modern design
