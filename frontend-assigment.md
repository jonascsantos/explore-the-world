# Paranormal Staff Frontend Engineer - Take-Home Assessment

## The Challenge
Build a React application that displays information about world countries using the REST Countries API.

**API**: `https://restcountries.com`

## Core Requirements
- Display countries from the API in a user-friendly way
- Use React + TypeScript

## Example Features (implement what makes sense to you)
- Search countries by name
- Filter by region or other criteria
- Show country details (population, capital, languages, etc.)
- Display country flags
- Sort functionality
- Detailed country view

## What We're Looking For
- Clean, maintainable code structure
- Good user experience and thoughtful prioritization
- Thoughtful component architecture
- How you handle real-world development constraints

## Evaluation Priorities (in order of importance)
1. **Working functionality** - Does it work reliably?
2. **Code architecture & quality** - Is it well-structured and maintainable?
3. **User experience** - Is it intuitive and handles edge cases well?
4. **Feature completeness** - How much you built (least important)

## Guidelines
- **Time**: ~ 3 hours
- **Libraries**: Feel free to use UI libraries like shadcn/ui, Ant Design, Tailwind, or similar to speed up development
- **Your call**: Choose which features to implement based on what you think provides the most value
- **Focus**: We value working software and good decisions over building everything from scratch

## Submission
- Git repository with clear commit history (zip file or in a hosted git (github, gitlab ...)
- README with setup and run instructions
- Will be nice if you could deploy it to a Cloudflare Worker and provide also the link
- Brief notes on what you prioritized and why
